Privacy Policy

Last updated: 2026

Short Uploader is a single-user automation tool. It does not collect, process, or store personal data from any third party.

The only data handled by this application is:

  • OAuth access/refresh tokens belonging to the developer's own connected accounts (YouTube, TikTok), stored as encrypted secrets in a private GitHub repository.
  • Video and audio files owned or licensed by the developer, used solely to generate and publish content to the developer's own accounts.

No data is sold, shared, or made available to any third party. No cookies or tracking technologies are used, as this application has no public-facing website or user interface.

For questions, contact the developer via the associated GitHub repository.
